## B. 끝나면 단계 1로

A가 전부 닫히면 `plan.md` §8 "단계 1 — 최소 수직 절편"과 §9 2주차로 넘어간다. 그때 첫 작업은 이미 정해져 있다.

1. **`--ring` light 대비 수정** — 확인된 유일한 접근성 결함. 2.82:1을 3:1 이상으로. `--accent-foreground`(7.92:1)가 이미 있으니 값 후보는 그 근처
2. **motion token 최소 집합** — easing 4종이 손으로 쓰였고 karaoke/blog가 곡선까지 다르다. 소비처 2곳 이상이 확인된 유일한 축
3. **`Button` / `ContentCard` 수직 절편** — Figma Variables까지 연결하고, D-010에 따라 공통 foundation을 사용하는 최소 Storybook으로 포커스 preset·상태를 검증한다. 자동 a11y 검사와 실제 Tab 이동, 표시 대비·잘림·가림 확인을 함께 다룬다

손대지 않기로 이미 정한 것: type / spacing token (`decision-log.md` D-005), `packages/ui`의 안 쓰이는 29개.
